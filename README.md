# SwiftSemanticVersion

[![](https://img.shields.io/endpoint?url=https%3A%2F%2Fswiftpackageindex.com%2Fapi%2Fpackages%2Forchetect%2Fswift-semantic-version%2Fbadge%3Ftype%3Dplatforms)](https://swiftpackageindex.com/orchetect/swift-semantic-version) [![](https://img.shields.io/endpoint?url=https%3A%2F%2Fswiftpackageindex.com%2Fapi%2Fpackages%2Forchetect%2Fswift-semantic-version%2Fbadge%3Ftype%3Dswift-versions)](https://swiftpackageindex.com/orchetect/swift-semantic-version) [![License: MIT](http://img.shields.io/badge/License-MIT-lightgrey.svg?style=flat)](https://github.com/orchetect/swift-semantic-version/blob/main/LICENSE)

Provides a `SemanticVersion` type for Swift.

This type conforms to the [SemVer 2.0.0](https://semver.org/spec/v2.0.0.html) specification.

## Getting Started

This library is available as a Swift Package Manager (SPM) package.

1. Add the **swift-semantic-version** repo as a dependency.

   ```swift
   .package(url: "https://github.com/orchetect/swift-semantic-version", from: "1.0.0")
   ```

2. Add **SwiftSemanticVersion** to your target.

   ```swift
   .product(name: "SwiftSemanticVersion", package: "swift-semantic-version")
   ```

3. Import **SwiftSemanticVersion** to use it.

   ```swift
   import SwiftSemanticVersion
   ```
